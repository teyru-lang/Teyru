# The divergences the back-end matrix is allowed to find, and why.
#
#   <program> <work item> <reason>
#
# scripts/backend-matrix.sh reads this file: a program listed here that the
# matrix finds diverging between its cells does not fail the run, and a listed
# program that has *stopped* diverging fails it, so an entry cannot outlive the
# divergence it describes. The mechanism is the one tests/known-failures.txt
# uses for a failing case; what is different is what is being excused: this file
# is about the two back ends disagreeing with each other, which the suite's own
# drivers cannot see, because they build one compiler with one back end.
#
# A divergence is listed only when it has been read, given a work item, and
# given a reason -- the same rule as the other two account files. "It is only the
# LLVM back end" is not a reason; *which* rule of the language one of them gets
# wrong is.
#
# --- the evaluation order of a string-concatenation chain (W8) has no entries
#     here any more. The C back end folded `a + b + c + ...` into one C
#     expression, and C leaves the order in which that expression's operands are
#     evaluated unspecified, where Java fixes it left to right (JLS 15.7) -- so
#     the same generated C answered differently under the two C compilers
#     whenever an operand had a side effect. t114_stream, t116_text,
#     t117_util_misc, t144_lombok_parity and t145_teyru_star_import were the
#     five programs a completed matrix run found with that signature, and the
#     run could not name the rule for a case in tests/programs, because such a
#     case passes under clang and fails under gcc and tests/known-failures.txt
#     has no way to say one without the other.
#
#     The generator now binds the operands that have to be bound to temporaries
#     in Java's order (`sequence`, internal/codegen/emit_expr.go), which is the
#     rule AGENTS.md §10 records, and tests/programs/t260_eval_order.teyru is
#     the case that could not be written before. All five programs agree with
#     the suite in every cell; a divergence here again means the rule has been
#     broken again, not that it is being excused.
